# 評価方式 v3

データTier、実測勝率、遭遇率、正準対面の勝敗とWilson区間は保存したv2スナップショットの値。更新は行わない。評価方式をreviewVersionで識別する。旧版の取り込みは各版の検証器を使う。

## 全対面の個別判断 evidence-judgment-v3

新規出力のテンプレートは、全登録の非ミラー対面を個別判断する。相性表と同じ遭遇率順（同率はID順）の上位8登録は重点対象。10戦以上の非ミラー対面は必ず5段階から個別に判定する。登録者偏り・先後差・期間差・資料の矛盾や不足・有意差の欠如は、結論の強弱と信頼度に反映する。不確実なら低信頼とし、自動的に五分にしない。1〜9戦は合理的な材料がある場合、0戦は対面固有の十分な直接資料がある場合のみ低信頼で判定する。結論・信頼度・反対材料・見直し条件を記録し、未観測対面も対象に含める。直接資料と戦績がともにない場合は明示的に保留。判定数・勝率による一律の割り当ては行わない。過去の文書の閲覧・再現は当時のルールを使う。新規の下書き保存・公開時は、入力形式にかかわらずスナップショットの10戦以上の非ミラー対面と公開用の判定を突き合わせる。欠落・保留があれば再評価が必要。

## 独立した総合判断 evidence-judgment-v1 / v2 / v3

遭遇率は環境の存在感の起点。encounter-v3.1を固定した実測比較値とし、別に原典を評価して最終Tier・対面を提案する。実測への同意、固定比率、資料の単純平均、基礎値からの変更幅を結論の必要条件にしない。独立した攻略表の一致には調査価値がある。順位だけの一致と、勝ち筋・構築・対象ランクまで再確認できた一致を区別する。

judgmentsには、対象ID、最終値、優先材料、信頼度、対象に対応する全参照ID、公開用の独自理由、内部用の反対材料、見直し条件を入れる。引用できるのは採用した直接の主張または同環境の現行本文に一意に照合した攻略表。攻略表のoutcome=不採用は旧方式の補正票からの除外を表す。新方式はその照合行を内部根拠として使える。未掲載、未知の構築、検索表示だけの資料、他デッキの記録は重みに使わない。対面には対面を直接扱う資料だけを使う。対象のない組や単なる欠測を五分にしない。

v1の実測行、およびv2のデッキ行は、対象別判断がない場合に基礎評価を引き継ぐ。v2の対面行は保留も明記する。有効資料がある行は据え置きにも判断を要求する。中信頼以上には件数・実測信頼度または利用できる直接根拠が必要。高信頼で評価する場合、直接の数値意見が割れる場合や全てが提案値と異なる場合には信頼度を下げ、実測の高信頼評価を変更する場合を含め、強い実測の支持がなければ低評価資料を除いた独立した複数系列を要する。系列は著者、原典URL、二次資料の参照元、データセットの共有を推移的に統合する。信頼度は最終値の上限にはしない。

外部優先、実測と乖離した対面、大幅な変更や前回差は手動公開時に確認する。システムが照合するのは資料ID、対象、版と時刻、重複、数値範囲、公開・内部の判断の整合。本文の真正性・独立性の申告・自由記述の意味は管理者が原典とともに確認する。以下の機械補正の記述はjudgmentRuleのない従来版で使用する。

## 比較基礎 encounter-v3.1

新規のv3TemplateにはtierRuleを明示。未指定のv3文書は従来方式で再検証し、履歴の数値を再計算して書き換えない。Aは実測v2、Bは遭遇率帯、Cは旧複合、Dは新実測補正、EはDに対象別資料を加えた値。前回公開版は同一戦績での方式比較とは別に扱う。

DではBおよび保留の入口は旧式と共通。上位5相手の全遭遇質量に占める採用対面（各10戦以上）の比率をqとする。観測主要対面の加重Wilson中心をFとし、方向の指標は50+q(F−50)。欠測対面には勝率を表示しない。2対面以上かつqが0.5以上で、方向指標が55超なら正、45未満なら負。それ以外は補正方向なし。全適格戦のWilson中心は全体成績の整合確認に使う。残余の勝率は内訳を説明するだけで、単独の昇降格には使わない。

正方向で遭遇推移・勝率推移・ランク差に逆方向がなければ最大1段階昇格。登録者集中・均等差・視点差がある場合、登録者均等勝率と最大登録者除外勝率が両方50%以上であることを追加で求める。負方向かつ全体Wilson中心50%未満、推移・ランクが降格と矛盾しなければ最大1段階降格。BがTier1に該当するときは主要対面が正、または適格10戦以上・全体中心50%以上・主要対面負ではない場合に最上位の根拠がある。条件を欠けばTier2。Bに出現がなく適格戦だけで基点を設定する場合は5から開始する。全体勝率や残余を主要対面と足し算しない。

Eの外部資料の採否・独立性・変更幅は従来と共通。v3.1では単一の外部見解との不一致など要検証の乖離がある場合、従来の信頼度「高」を「中」までとする。Bからの累積変動が2段階以上なら管理者に対象・理由を表示する。対面の有利不利判定は従来と同一。

## 主要攻略表との内部比較

新規の手動調査ではGameWith・Game8の現行ローテーション表を最初に確認する。各サイトの記事版・環境・対象デッキを照合したうえで、実測補正後のDに対する方向だけをguideCheckに記録する。取得不能や旧環境の検索結果は候補にとどめる。本文確認済みの表はスナップショットの全対象について一致・相違・対応不明・掲載未確認・自サービス評価保留を記録する。非掲載は弱さの証拠としない。

攻略表との差が重点調査の入口になる。実測の登録者構成・ランク・主要対面、外部の構築差・プレイ判断・大会形式を照合し、補正または据え置きの理由を残す。参照した順位表は内部比較専用で採用票を持たない。別原典の直接根拠には既存の独立性・補正幅の条件を適用する。名称のNFKC正規化・空白・大文字小文字で一意に照合し、別名はその回に根拠のあるID指定を使用する。未対応名を管理者のマスタ照合候補とし、複数の構築が同じIDを指すときは比較保留。公開投影に外部名称・比較表を含めない。公式の変更が同一環境IDにある場合、balanceChangeの境界より前の根拠、対象期間の確認が取れない根拠、変更前後が混在する実測を拒否する。

重点調査は実測と攻略表の上下差、外部見解の分裂、直接対面資料との食い違いを優先する。次に遭遇5%以上かつ適格勝率50%未満、1〜19戦で上位Tierまたは勝率60%以上、遭遇・勝率・ランクの変化、新たに観測された構築、前回との差2段階以上を確認する。主要同士の不確定対面も提示する。基準は調査の優先順を表し、Tierには加点しない。同一優先群は当該デッキの遭遇率（対面では両者の小さい方）とIDで整列する。前回公開がない場合は初回掲載を新登場と断定しない。

比較記録がない旧JSONも元のルールで検証する。

## 旧v3.0の強さ・信頼度・対策頻度

Bの参考帯は相手側の遭遇率（元の精度、全戦を分母）10・5・2・1%以上を順にTier1〜4、正で1%未満をTier5。未観測は参考帯なし。10戦・20戦・50戦・100戦に1回という頻度で、既存週報の対策優先度10・5%とも対応する。件数による上位枠やデッキ別係数は設けない。

CはBから開始する。相手としての観測5件未満かつ適格戦10件未満は保留。相手側ゼロでも適格戦10件以上なら基点5。相手側遭遇の多い順に選んだ上位5デッキ（自身除外）のうち10戦以上の対面を用い、各対面のWilson中心を相手の遭遇シェアで再加重する。加重値55超を正、45未満を負とする。対象試合を勝敗ごと引き、残り10戦以上のWilson中心53以上を正・47以下を負とする。全勝率も併記する。対面結果と全勝率を二重に加点しない。

主要対面の符号を優先し、中立・欠測時は残りの対面の符号を使う。両者が逆なら元の帯を維持する。直近3日とそれ以前の相手側遭遇率の95% Wilson区間が分離した時だけ増減を使う。既存GM帯差または遭遇推移が成績方向と逆なら移動を見送る。整合すれば上下1段階。主要対面・残りがともに正、直接観測した主要対面が2組以上、集中・登録者均等差・視点差なしなら上方2段階まで。Tier1には独立した成績面の上方材料が必要で、指標分裂や減少・負のランク差があればTier2までとする。これらは試験運用の解釈可能な帯であり最適化済みの係数ではない。

信頼度は値と別に計算。登録者集中、使用・反転差、均等化差、区間幅を含む既存の実測信頼度を使い、主要対面も直接資料もない場合の高は中まで。変更、出典の意見分裂、保留からの採点は低。値なしは判断保留。数値にできない構築・プレイ難度・大会採用は理由と条件で補完する。対策優先度は遭遇率10%以上を高、5%以上を中、それ以外を低とする。

## 対面

確定区分はv2のまま。表示順は総合Tier→遭遇率→ID。逆側では勝敗・区間・方向を反転。保留時は未観測、1〜9戦の少数参考、10戦以上でWilson中心が55超で有利傾向、45未満で不利傾向、他は実測は拮抗。五分には95%区間全体が45〜55に収まることが必要。

## 補完

同じ対象に直接付けた資料のみ。外部評価の数値なしは構築・採用事情の補完だけ。値ありの全資料が同じ評価を示し、独立2系列以上ならCから原則1段階。デッキは3系列一致かつ高信頼の直接実戦検証ありで最大2段階。保留デッキは2系列一致で暫定Tier2〜4、同じ3系列＋実戦検証条件でTier1を提案できる。保留対面は直接の非中立意見で最大±1、10戦以上の実測傾向（Wilson中心が55超または45未満）と逆なら2系列が必要。保留から五分への置き換えは認めない。採用原典のURL・著者・原データを推移的に統合。低信頼・異なる環境・未来・古い環境評価を拒否する。研究資料の真正性・利用条件は管理者が原典で確認する。

確定済みの有利・不利と逆方向の外部意見は乖離として扱い、補正の途中で五分を作らない。データ相性の保留時も実測傾向と外部意見が逆なら要検証とする。

乖離はCと外部資料に示される評価値を比較する。評価値がなく補完だけなら乖離なし。差があれば要検証、2系列一致かつ実測信頼度中以上・20戦以上で確認済み。補正があれば重要度4、据置で2系列以上なら3、1系列なら2。対象デッキ（対面では双方）の遭遇率が5%以上なら1加算、最大5。公開画面では重要度降順、同順位はID順。過去の公開版と2段階以上離れる場合・大幅補正は手動確認する。v3は手動実行に限定。
