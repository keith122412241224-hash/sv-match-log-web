# 総合評価・入力検証の運用基準

対象スキーマは `schemaVersion = 1`、信頼度は `review-confidence-v1` です。入力の形は [JSON Schema](input.schema.json)、入力例は [架空の分析結果](sample.json)、ChatGPTに渡す文面は [分析プロンプト](prompt.md) にあります。実測値とデータ評価の計算は [エクスポート仕様](export.md) を参照してください。

## 入力と照合

公開用の要約・理由・確信度・乖離と、管理者用の資料・考察・取得失敗を別のオブジェクトに格納します。全オブジェクトで指定外の項目を拒否します。数値項目は総合Tier、総合対面評価、重要度、スキーマバージョンです。実測値、デッキ名、データTierや前回のTierの追加は取り込みエラーとなります。必須文字列は前後空白を除いて検証します。

| 項目 | 取り込み時の照合 |
| --- | --- |
| 実測・期間・ランク | サーバーの保存済みスナップショットを表示・比較に使用 |
| 環境・スナップショット | 実行情報の両IDと一致。外部資料も同じ環境ID |
| デッキ | マスターに結び付いたスナップショットの全IDを各1件。評価保留も含む |
| 対面 | 記録された非ミラーだけ。a・bはID昇順でa視点。逆向きは表示時に符号反転。省略対面は保留 |
| 内部根拠 | 全デッキ・全入力対面に対して各1件。targetはdeckIdまたはa/b。参照資料IDは実在し、重複なし |
| 外部資料 | HTTP(S)のみ。URLのフラグメントを除いて重複を判定。認証情報付きURLを拒否。資料IDも一意 |
| 公開文 | URL・HTMLを拒否。管理者は実測値の文章内転記、引用条件、外部資料や著者の特定情報の混入を公開前に確認 |

## 総合評価

管理者がエクスポート時点のデータ評価を出発点に、ChatGPTの説明と参照資料を確認して公開します。Tierの意味は1が環境トップ、2が上位、3が中堅、4が下位、5が現環境で厳しいです。対面評価はa視点で2がかなり有利、1がやや有利、0が五分、−1がやや不利、−2がかなり不利です。根拠が不足する場合は null を指定します。

データ評価が保留の対象は総合評価も保留です。データ評価が付いた対象でも総合評価を保留にできます。実測と違う総合判定には、対象期間内に公開された一次系統の資料（信頼性中以上）、比較可能な傾向、公開理由、内部判断根拠が必要です。環境への適性、主要対面の勝ち筋、構築・練度、個人寄与の偏り、大会とランク戦の母集団の違いを検討します。実測と外部評価を混ぜる定率の計算は行いません。

## 乖離の判定

| 比較結果 | 公開表示 |
| --- | --- |
| 実測より外部評価が強い／弱い | 過小評価／過大評価の可能性 |
| 独立資料が2系列以上あり、その評価に不一致がある | 評価が分かれている |
| 比較資料不足、件数不足だけ、追加検証のみ | 通常は乖離なし。調べるべき具体的な対面・理由があるときは「要検証」「判断保留」 |

「確認済み」は評価の差を確認できたことを表します。理由の因果関係やデッキの真の強さまで確認したことを意味しません。期間内の信頼できる比較根拠、方向の一致、実測件数が1以上という条件を検証します。データTierと総合Tierが同じでも、確認できた差を登録できます。重要度は5が最大です。主要デッキ・対面への影響、差の大きさ、資料の独立性と鮮度を考慮して管理者が決定します。

同じURL・同じ原典の転載で根拠件数を増やさないようにします。URLの正規化で検出できない転載・異なるURLの同一記事は管理者が同じgroupにまとめます。日付不明、基準日時より後、期間開始より前、資料信頼性「低」の情報は保存しても比較根拠に数えません。v1では同環境でも7日より古い論考単独で今回の乖離を確認済みにできません。

## 評価信頼度

| 信頼度の上限 | 必須の判断材料 |
| --- | --- |
| 判断保留 | 総合評価を決定できない、またはデータ評価の品質条件を満たさない |
| 低 | 総合評価を付けたが、中の条件を満たさない |
| 中 | デッキのTier対象評価件数（対面は実対戦件数）20以上、期間内に公表された信頼性中以上の独立資料1系列以上、対象への比較可能な評価 |
| 高 | 中の条件と、独立資料2系列以上、評価分裂なし、対象の集計利用者3人以上、最大集中度50%以下をすべて確認 |

件数20は既存週報の「参考値」区間（10〜19件）の上限に従います。独立資料・利用者数・集中度の線引きはv1の編集上の上限であり、勝率が正しい確率ではありません。対面別の集計利用者数と集中度が得られない場合、対面評価は「中」までです。管理者は実際の説明や根拠の質から上限内で引き下げられます。基準変更時は信頼度ルールとデータルールの両バージョンを更新し、履歴を遡及修正しません。

## サンプルの確認条件

同梱サンプルは架空の資料・IDを使ったローカルテスト用です。架空スナップショットの集計期間は2026年9月1日00:00 UTC〜9月7日03:00 UTC、デッキ甲は22評価・データTier3、乙は40評価・データTier2、甲対乙は15件・データ相性0です。甲の「過小評価の可能性」と甲対乙の「過大評価の可能性・要検証」を示します。実運用では管理画面から新規エクスポートしたID・実測を使ってください。
